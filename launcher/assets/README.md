# Maria assets

`icon.svg` is the editable Maria brand source. The PNG and ICO are exports of this
same mark; the browser connector uses the same PNG. macOS ICNS files are produced
by electron-builder from the PNG when packaging.

The Chrome, Edge, and Safari PNGs identify the corresponding installed browser in
the sign-in chooser. They are 128px exports of those applications' supplied icons.
Browser names and marks belong to their respective owners.
